# SeanTheAtom GitHub Pages files

The repository's GitHub Actions workflow deploys the repository root to GitHub Pages. These are the static site files that need to be added to that root:

- `index.html`
- `mad-scientist.css`
- The image and GIF files referenced by `index.html`

To publish, sign in to GitHub with an account that can push to `jjjustjammin/SeanTheAtomChemistru`, upload these site files to the repository root, and commit them to `main`. The existing Pages workflow will deploy the site after the commit. Keep the filenames unchanged so the page can load its stylesheet and images.

The visitor feedback box saves its note only in that visitor's browser; it does not send feedback to a central account.
